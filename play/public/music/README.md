# Música de fundo (extra, fora do jogo original)

Aqui vão as músicas **de verdade**, se você quiser usar os arquivos originais.
O jogo procura por estes nomes (qualquer uma destas extensões: `.mp3`, `.ogg`, `.wav`):

| Arquivo | Quando toca |
| --- | --- |
| `uniao-flasco.mp3` | tela inicial, antes de entrar numa partida |
| `vida-de-empreguete.mp3` | lobby, sorteada entre as três |
| `bombapet.mp3` | lobby, sorteada entre as três |
| `jin-sheng-yuan.mp3` | lobby, sorteada entre as três |

Regras:

- Lobby = partida criada e **ainda não começada**. A cada entrada no lobby uma das três
  é sorteada (nunca a mesma da vez anterior) e fica em loop, baixinho.
- Assim que a partida começa a música para; os efeitos do jogo continuam.
- O volume é baixo de propósito (barramento próprio a 18%) e o botão **♪ MÚSICA**
  no canto inferior direito liga/desliga só a música (fica salvo no navegador).
  O botão **SOM** do jogo silencia tudo.
- Se o arquivo não existir, o jogo toca uma **versão instrumental sintetizada**
  (chip) daquela faixa, gerada no próprio navegador — nada é baixado.
- Os arquivos **não estão incluídos** neste repositório: são gravações comerciais
  e os direitos são dos autores. Coloque aqui só arquivos que você tenha direito de usar.
